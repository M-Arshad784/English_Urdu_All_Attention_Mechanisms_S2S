# English to Urdu Translation using Attention Mechanisms

## Overview

This project focuses on **English-to-Urdu translation using a Sequence-to-Sequence (S2S) Deep Learning model** with different attention mechanisms.

The model learns relationships between English input sequences and their corresponding Urdu translations. Attention mechanisms help the decoder focus on the most relevant parts of the English input while generating the Urdu output.

## Project Workflow

1. Prepare the English-Urdu translation dataset.
2. Clean and preprocess the text.
3. Tokenize English and Urdu sentences.
4. Convert sentences into numerical sequences.
5. Prepare training and testing data.
6. Build the Encoder-Decoder S2S architecture.
7. Implement different attention mechanisms.
8. Train the translation models.
9. Evaluate the models.
10. Generate Urdu translations from English input.
